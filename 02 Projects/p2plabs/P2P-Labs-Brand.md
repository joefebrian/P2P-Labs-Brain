# P2P Labs — Brand

Source files in vault: PDF + [[P2P-Labs-Design-System]] + `P2P-Labs-Logo-horizontal.png`.

**Lead line:** **People to Prosperity.**

Prosperity = **memakmurkan orang** — we work so people can prosper. That is the meaning we highlight.

The second **P** can also read as:

| P | When we use it |
|---|---|
| **Prosperity** | Default. The one we put in the headline. |
| **Performance** | When the work is about results. |
| **Partner** | When the work is with brands / agencies / teams. |
| **People to People** | When the work is peer collaboration. |

Do **not** lead with the old PDF decode (People · Partners · 2 peer-to-peer) as the public line. Labs still means we build the tools.

**P2P Network:** do not put it on p2plabs.asia. Later it is a **service**, not a public sub-brand on this site. Do not use the Network cyan/pink palette here.

## Visual (site)

- Logo: official **horizontal** lockup (trimmed PNG in this folder + on the VPS).
- Canvas: **light** — white / `#F3F4F8`. Joe: not too dark.
- Text: Deep Navy `#0B0F2B`. CTA: Vivid Purple `#652DFF` + white label. Lime `#A6FF1A` = accent only.
- Layout language (2026-09-02): Awesomic geometry (36px cards, 14px buttons, pill nav CTA, hairline borders, 80px sections) **recoloured** to Labs tokens. Do not bring Awesomic zinc/orange/magenta onto the site.
