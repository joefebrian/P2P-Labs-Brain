# Hook Library

> Real opening lines (first spoken sentence) from the analysed videos, grouped by hook type. Each is verbatim from the faster-whisper transcript (small transcription errors are possible) and attributed as `style-Ad-N-Brand`. Formulas `{…}` are the reusable pattern. Back to [[00 UGC Playbook – Index]] · Spec ids used by [[05 AIOSCreator Script Generator Spec]].

## How to use
1. Pick 3 hook types that fit the product and audience awareness (see [[04 Style Selection Guide]]).
2. Adapt one formula per type, and pair each spoken hook with a **different** on-screen text and first visual.
3. Keep the body the same and test the hooks against each other. Spoken hooks in the data run about 8–12 words (≈3 s at the median pace of 187.5 wpm).
